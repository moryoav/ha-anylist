# Support

Thanks for using AnyList for Home Assistant.

## Getting Help

Start with the project documentation:

- `README.md` for installation, setup, examples, limitations, and troubleshooting.
- `custom_components/anylist/services.yaml` for action fields and examples.
- `custom_components/anylist/quality_scale.yaml` for current quality-scale status.

## Reporting Bugs

Use the bug report issue template when something is not working as expected.

Please include:

- Your AnyList for Home Assistant version.
- Your Home Assistant version.
- Your installation method.
- Clear reproduction steps.
- Relevant Home Assistant logs with sensitive information removed.

Do not include AnyList credentials, tokens, private URLs, shopping list contents, recipes, personal paths, or private Home Assistant configuration.

## Feature Requests

Use the feature request issue template for new ideas or improvements.

Please explain the Home Assistant workflow you want to improve and whether the change affects shopping lists, recipes, meal planning, actions, entities, setup, or diagnostics.

## Security Issues

If you believe you found a security vulnerability, do not open a public issue with exploit details. Follow `SECURITY.md`.

## Scope of Support

This project is community maintained and may not have immediate support. It is an unofficial integration and is not affiliated with AnyList or Purple Cover, Inc.

Keep backups of your Home Assistant configuration and verify important automations after changing integration versions.
